# 출혈·반격과 정식 보상 카드

## 카드와 보상 풀

- 고급 `bleed_attack_001` 출혈 공격: 피해 4, 출혈 3, 비용 15, 재사용 대기 1턴.
- 희귀 `riposte_stance_001` 응수 태세: 보호막 10(1슬롯), 반격 피해 8, 비용 20, 재사용 대기 2턴.
- 전설 `tear_wound_001` 상처 찢기: 피해 6 + 대상 출혈 × 3, 비용 25, 재사용 대기 2턴. 출혈을 소비하지 않는다.

세 카드는 방향을 지정하며 기본 범위는 `(0,0);(1,0)`이다. 시작 덱에는 포함하지 않는다. 맵과 전투는 정식 CardDatabase를 사용하며, 획득 가능한 카드는 일반 머리깨기와 위 세 카드다. 기존 개발 DB와 더미 8종은 보존한다.

## 실행 순서

각 슬롯은 기본 행동 및 동시 피해 → 반격 판정 → 플레이어 반격 연출 → 적 반격 연출 → 반격 동시 피해 → 출혈 및 슬롯 종료 처리 순서다. 발동할 반격이 없으면 반격 연출과 대기는 실행하지 않는다.

반격은 해당 슬롯 기본 공격에 적중당하고 기본 피해 처리 후 살아 있는 유닛만 발동한다. 실제 HP 피해가 0이어도 적중으로 인정하며, 여러 번 또는 여러 대상에게 맞아도 유닛당 슬롯당 1회다. 양측 발동 여부를 먼저 확정하므로 반격으로 동시에 사망할 수 있다. 반격 피해와 출혈 피해는 반격을 유발하지 않는다. 범위는 카드의 예약 방향과 반격 시점 위치를 사용한다.

출혈은 합산한다. 부여된 현재 슬롯 끝부터 현재 수치만큼 보호막을 무시하고 HP 피해를 주고 1 감소한다. 출혈 3의 피해는 3·2·1이다. 남은 출혈은 다음 턴으로 이월되며 전투 유닛 상태에만 보관한다.

## 시트 필드와 표시

Card Effect Data의 `triggerTiming`은 빈 값 또는 `action`이면 기본 효과, `counter`면 반격 조건 효과다. 반격 피해는 `damage` 효과 자체에 값과 범위를 둔다. 출혈 부여는 `applyStatus`, `statusId=bleed`와 앞선 피해 효과의 `triggerEffectId`를 사용한다. 출혈 비례 피해는 `damage`, `statusId=bleed`, `statusMultiplier=3`으로 표현한다.

Keyword Data의 `textColor`는 `#RRGGBB`다. 출혈은 `#FF5A5A`, 기절·반격·방향지정은 `#FFBA47`이며 누락된 기존 데이터는 `#FFBA47`로 표시한다. 카드 내 링크와 키워드 툴팁 제목이 같은 색상을 사용한다. 유닛 HP 표시에는 남은 출혈 수치를 덧붙인다.

## 검증

Unity 메뉴 `Tools > Duel Hero > Cards > Validate bleed and counter`에서 데이터, 설명 치환, 방향 복제, 출혈 틱·중첩·방어 무시·턴 이월, 반격 조건·중복 방지·동시 처치·범위, 미리보기와 AI의 조건부 피해 제외를 검증한다. 성공 로그는 `CARD_MECHANIC_VALIDATION_PASS`다.

2026-11-03 Unity MCP 검증:

- 위 검증과 기존 `StunValidation.Run`, `CardRewardValidation.Run`, `EnemyPlanSimulationValidation.RunUtility` 통과.
- 실제 BattleScene에서 기존 카드 추가 API로 세 카드를 별도 사본으로 추가하고 일반 `TryExecute` 흐름으로 실행.
- 양측 HP 100, 플레이어 에너지 100에서 세 카드 순서대로 예약, 적은 베기·베기·대기. 슬롯별 적 HP 93 → 83 → 73, 출혈 2 → 1 → 0, 플레이어 에너지 85 → 65 → 40. 플레이어 최종 HP 90. 두 번째 슬롯의 보호막으로 HP 피해가 0이어도 반격 1회 발생.
- 카드 프레임과 키워드 색상을 게임 화면에서 확인. 캡처: `Captures/CardMechanics/three-cards-result.png`.
- 플레이 종료 후 콘솔 오류 0건. 씬 내 테스트 배치와 추가 카드는 저장하지 않음.

수동 테스트는 기존 `Duel Hero > Debug > Card Hand and Stats`에서 카드를 추가한다. 전용 카드 추가 버튼이나 새 디버그 단축키는 만들지 않는다.
