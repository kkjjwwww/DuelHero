# 기절과 머리깨기

머리깨기는 일반 공격 카드다. 피해 3, 기절 1, 에너지 20, 쿨다운 2턴이며 전투 보상으로 획득한다. 시작 덱에는 포함하지 않는다. 기존 개발용 보상 DB에도 정식 카드 정의를 반영하며 더미 보상 카드는 보존한다.

## 실행 규칙

- 기절 수치는 합산한다. 각 슬롯 시작에 양측의 기절을 먼저 소비한 뒤 행동을 실행하므로 새로 받은 기절은 현재 행동을 취소하지 않는다.
- 적중한 공격의 연결된 `applyStatus` 효과만 부여한다. 실제 체력 피해가 0이어도 부여하며, 빗나가면 부여하지 않는다.
- 차단된 슬롯은 `StunCard` 표시로 대체한다. 예약된 카드의 예약을 해제하고 뒤 슬롯을 당기지 않으며 에너지와 쿨다운을 소비하지 않는다.
- 남은 기절은 다음 턴 앞 슬롯부터 차단한다. 모든 슬롯이 막혔어도 행동 실행으로 세 슬롯을 진행할 수 있다.
- 기절은 전투 중 유닛 상태이며 런 덱이나 보상 후보에 들어가지 않는다.

## 데이터와 표시

상태 정의는 `Keywords.csv`의 `category / stackRule / countUnit`에서 가져온다. `Keyword Data`의 기절·출혈 행에 키워드 설명과 상태 정의를 함께 작성하며, 상태 ID는 해당 키워드 ID와 같다. `statusId`는 상태 정의, `triggerEffectId`는 같은 카드 내 앞선 피해 효과를 참조한다. 상태 효과가 있는 데이터는 해당 상태 정의가 반드시 필요하다.

기절 전용 프리팹은 `Assets/Resources/StunCard.prefab`이다. 기존 CardView를 기반으로 특수 아이콘, 숨긴 코스트 배지, 이름 ‘기절’, 설명 ‘아무 행동도 할 수 없다.’와 균열 UI 그래픽을 사용한다. 양측 슬롯에서 같은 프리팹을 로드하며 Inspector의 별도 프리팹 참조로 교체할 수도 있다. 씬 변경은 필요 없다.

## 검증

Unity 메뉴 `Tools > Duel Hero > Cards > Validate stun`에서 실제 전투 실행 루프를 동기적으로 진행하는 검증을 수행한다. 체력 피해 0 적중, 빗나감, 중첩, 현재 슬롯 실행, 다음 예약 취소와 위치 유지, 비용·쿨다운 제외, 마지막 슬롯 기절의 이월, 두 번째 슬롯부터 예약, 전 슬롯 차단, 미리보기, 적 AI 계획과 전용 프리팹을 확인한다. 결과 로그는 `STUN_VALIDATION_PASS`다.

`Tools > Duel Hero > Cards > Set up stun assets`는 저장된 시트 CSV를 DB에 반영하고 개발용 DB의 정식 카드 정의와 프리팹을 갱신한다. 열린 씬을 저장하지 않는다.

수동 플레이 확인: 머리깨기 보상 획득 후 공격 범위 내에서 예약하여 적의 다음 슬롯 교체를 확인한다. 적에게 기절을 부여하는 테스트와 반대로 플레이어가 기절하는 테스트도 진행하여 예약 차단, 외형, 턴 이월을 함께 확인한다.

## 플레이 모드 디버그

`Duel Hero > Debug > Card Hand and Stats`의 기존 ‘손패 카드’ 영역에서 공격 카테고리의 머리깨기를 선택해 추가한다. ‘기절 테스트’ 영역에서는 기절 수치(1~99)를 입력해 플레이어 또는 적에게 부여한다. 반복 부여는 합산한다. 추가한 카드는 기존 ‘추가한 테스트 카드만 제거’로 제거할 수 있으며 플레이 종료 시 유지되지 않는다.

새 디버그 조작은 준비 단계에서만 허용한다. 실행 중, 실행 결과 표시 중, 턴 복원 중, 전투 종료 후에는 UI와 실행 메서드에서 모두 거부한다. 준비 중 기절로 취소된 예약 뒤의 카드는 원래 슬롯을 유지한다.

슬롯 정보 열람은 행동 수정과 별도다. 준비 및 다음 턴 진행 전 결과 확인 단계에서 양측 기절 카드를 호버하면 전용 외형으로 확대한다. 결과 확인 중 슬롯 카드의 키워드 설명도 볼 수 있다. 확대된 기절 카드에는 클릭 동작이 없으며, 결과 확인 중 예약 취소·방향 수정은 계속 차단한다. 실제 실행, 턴 복원, 전투 종료 및 보상 표시 중에는 슬롯 정보 열람을 막고 열린 확대/툴팁을 닫는다.

`Duel Hero > Debug > Validate Stun and Capture`는 정지 상태에서 실행한다. 실제 BattleScene을 플레이 모드로 로드해 디버그 추가/부여, 입력 잠금, 머리깨기 실제 적중과 비용/쿨다운, 기절 이월과 중첩, 예약 차단을 검증하고 `Captures/Stun/PlayMode/`에 게임 화면 3장을 저장한다. 적 이동으로 인한 테스트 변동을 막기 위해 적에게 기절 3을 부여하고 공격 범위 안으로 배치한다. 씬과 런 데이터는 저장하지 않으며 완료 시 플레이 모드를 종료한다. 결과는 `Temp/StunPlayTest.result`의 `ALL_PASS`로 확인한다.
