# 골드·전투 보상·상점

## 데이터 갱신

`RunConfig`, `BattleRewardConfig`, `ShopConfig` 탭을 기존 시트 동기화 창의 **전체** 또는 **골드·보상·상점 설정** 범위로 가져온다. 저장된 CSV는 `Assets/Data/EconomySheets`에 있고, 설정 에셋은 `Assets/Data`에 각각 생성된다. 필수 키 누락·중복, 음수, 0인 상품 수와 전체 희귀도 가중치는 임포트를 거부한다. 모든 설정을 파싱한 뒤 기존 임포터의 일괄 저장·복원 흐름을 사용한다.

2026-11-04 반영 값: 시작 골드 30, 일반전 승리 30, 보스 승리 100, 상품 4종, 일반·고급·희귀·전설 가격 30·50·80·120, 추첨 가중치 62·25·10·3.

## 런과 보상

`RunSession.Gold`가 보유 골드의 기준이다. 맵에서 새 런 생성 시 시작 골드를 전달한다. 기존 호출 호환용 생성자와 API의 골드 기본값은 0이며, 운영 맵에는 RunConfig를 명시적으로 연결했다.

일반전은 카드 선택 또는 스킵 시 `TryCompleteBattle`에서 HP·덱·골드·노드 완료를 함께 반영한다. 지급 전까지 승리 화면에 획득 예정 골드를 표시한다. 카드 보상을 스킵해도 골드는 지급한다. 보스는 기존 종료 흐름에서 보스 골드를 지급한다. 패배·무승부·런 없는 단독 전투는 골드를 지급하지 않는다. 결과 확정 후 맵 이동을 재시도해도 다시 지급하지 않는다.

## 상점

모든 상점 노드는 `Assets/00.Scenes/ShopScene.unity`를 사용한다. 맵과 전투 씬의 필요한 참조를 연결하고 빌드 씬 목록에 상점을 추가했다. 배경은 임시 UI다.

- `TryBeginShop`: 선택 가능한 상점 노드에서 상품을 생성하고 방문 상태를 보관한다. 아직 다음 경로를 열지 않는다.
- `ShopOfferSelector.Generate`: `shop:` 접두사·런 시드·노드 ID로 독립 난수를 생성한다. 정식 획득 가능 카드만 대상으로 희귀도 우선, 등급 내 균등 추첨한다. 소유 카드 감점은 없다. 같은 종류의 중복 진열은 없고 후보가 부족하면 가능한 수만 진열한다.
- `TryBuyShopOffer`: 방문과 인덱스·잔액·품절 여부를 검사해 골드 차감, 덱 ID 사본 추가, 품절 처리를 함께 반영한다. 이미 소유한 카드도 구매할 수 있으며 다음 전투에서 별도 CardInstance로 생성된다.
- `TryCompleteShop`: 나갈 때 노드를 완료한다. UI는 완료 여부와 상품 목록을 보존하여 이동 실패 후 이동만 재시도한다.
- 같은 방문의 씬 재로드에서도 상품·가격·품절 상태를 유지한다. 앞으로 진행해 다른 상점 노드에 진입하면 해당 노드의 상품을 생성한다. 이전 상점으로 돌아가는 기능은 없다.
- 런 없이 상점 씬을 실행하면 안내를 표시하고 구매를 차단한다. 나가기 버튼으로 맵에 진입할 수 있다.

현재 맵 생성 규칙은 경로마다 휴식 또는 상점 유틸리티 노드 1개를 포함한다. 이 작업에서는 맵 생성 규칙을 변경하지 않았다. 상품 생성 자체는 임의의 상점 노드 ID를 구분해 동작한다.

카드 프레임·일러스트·키워드 툴팁은 기존 CardView를 재사용한다. 호버 시 기존 ButtonHoverScale의 DOTween으로 해당 카드의 VisualRoot를 제자리에서 확대한다. 별도 확대 카드는 생성하지 않는다. 상품 카드를 클릭하면 즉시 구매하며 하단에는 가격 또는 품절 텍스트만 표시한다. 품절·잔액 부족 상태에서도 호버와 키워드 설명을 볼 수 있다.

ShopScene의 ShopCanvas 아래 비활성 `CardHoverTemplate`에 기존 ButtonHoverScale 설정을 보관한다. Inspector에서 Hover Scale(기본 1.15), Transition Duration(기본 0.1초), Ease(OutQuad)를 조절한다. 상품마다 이 설정을 복제해 사용하므로 공용 호버 코드와 전투 UI는 변경하지 않는다. 나가기·비활성화 시 Tween과 크기를 초기화한다. 기존 씬의 호버 연결만 갱신하려면 `EconomySetup.ConfigureShopHover()`를 실행한다.

## 검증

`Tools > Duel Hero > Economy > Validate gold and shop`에서 시작/전투/보스 골드, 중복 완료, 원자적 구매, 잔액 부족과 품절, 방문 유지와 완료, 재현성·DB 순서 독립성·희귀도 추첨·전역 난수 보존·후보 부족과 제외, 잘못된 임포트의 기존 에셋 보존을 확인한다.

초기 에셋 연결은 `Tools > Duel Hero > Economy > Set up gold and shop`으로 재현할 수 있다. 기존 ShopScene은 덮어쓰지 않으며, 저장하지 않은 대상 씬이 있으면 중단한다. 기존 카드·유닛 DB와 프리팹을 다시 만들지 않는다.

Unity MCP 실제 플레이 검증:

- 맵에서 새 런 골드 30, 일반전 승리 후 카드 선택/스킵 각각 골드 60 확인.
- 잘못된 맵 경로로 이동 실패를 발생시키고 반복 입력해도 골드 60 유지, 올바른 경로 복구 후 이동 확인.
- 상점 4종·가격 표시, 머리깨기 구매 후 골드 30 및 품절, 같은 상품 재구매와 잔액 부족 구매 거부.
- 상점 씬 재로드 후 상품·품절·골드 유지, 이동 실패 후 상점 나가기 재시도 확인.
- 보상으로 받은 머리깨기와 구매한 머리깨기가 다음 전투에서 별도 사본으로 존재. 구매 사본을 예약하고 실행해 에너지 20 소모, 다음 턴에 사용 사본에만 쿨다운 적용.
- 보스 승리 골드 100 지급과 런 완료, 보스 카드 보상 미추가 확인.
- 상점 단독 실행 안내 및 구매 거부 확인.
- 골드·상점 검증, 기존 카드 보상·맵 생성/진행·기절·카드 기믹 회귀 검증 통과. 중첩 준비 코루틴을 실행하도록 기존 동기 검증 Fixture를 보완했다.

화면 캡처는 `Captures/Economy/`에 저장했다. 플레이 중 추가한 카드·노드 진행은 씬에 저장하지 않았다. 유료 새로고침, 카드 판매/제거, 실행 종료 후 이어하기, 전용 아트는 포함하지 않는다.

상점 조작 변경 후 추가 검증:

- 반복 진입/이탈 후 1.15배 확대와 원래 크기 복귀 확인. 카드 위치·루트 배율·가격 위치 유지, 별도 CardInspectionPresenter 0개.
- 상품에는 CardView 자체 버튼만 존재하고 별도 구매 버튼은 없음. 하단 가격 텍스트는 레이캐스트를 받지 않음.
- 실제 카드 버튼 클릭으로 50골드 상품 구매: 골드 60 → 10, 덱 사본 +1, 가격 대신 품절 표시. 반복 클릭과 잔액 부족 카드 클릭으로 추가 차감·추가 지급 없음.
- 품절·잔액 부족 카드의 호버 확대와 키워드 툴팁 유지. 컨트롤러 비활성화 시 원래 크기 복구 및 Tween 종료, 정상 맵 복귀 확인. 콘솔 오류 0건.
- 변경 후 화면: `Captures/Economy/shop-inline-hover.png`. 기존 캡처 중 구매 버튼이 보이는 것은 초기 구현 기록이다.
