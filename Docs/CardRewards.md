# 전투 승리 카드 보상

일반 런 전투에서 승리하면 결과 패널에 카드 최대 3장이 표시됩니다. 카드를 클릭하면 즉시 한 장을 별도 사본으로 획득하고 맵으로 돌아갑니다. `건너뛰기`는 카드 추가 없이 전투를 완료합니다. 보스전, 패배, 단독 BattleScene 실행에는 보상을 지급하지 않습니다.

## 추첨 설정

`Assets/Data/CardRewardSettings.asset`에서 설정합니다.

- 일반/고급/희귀/전설: 62/25/10/3.
- 소유 카드 배율: 0.25. 사본 수가 늘어도 추가 감점하지 않습니다.
- 등급을 먼저 뽑은 다음, 해당 등급 안에서 미소유 1 : 소유 0.25로 추첨합니다.
- `isObtainable`이 켜진 카드만 사용합니다. 기본 행동과 시스템 대기는 제외합니다.
- 한 화면에 같은 ID를 중복 표시하지 않으며, 후보가 소진된 등급은 나머지 등급에 가중치를 재분배합니다. 따라서 62/25/10/3은 모든 등급에 후보가 있을 때의 매 추첨 기준이고, 화면 3장의 확정 구성비는 아닙니다.
- 런 시드와 노드 ID가 같고 카드 DB/보유 카드/설정이 같으면 같은 후보를 생성합니다. 전투 종료 후 화면을 다시 활성화해도 다시 추첨하지 않습니다.

후보가 부족하면 가능한 수만 표시합니다. 후보가 없으면 안내와 `계속` 버튼을 표시합니다. 획득 결과는 맵 이동 전에 런에 한 번 반영되며, 맵 로드 실패 시 `계속`으로 이동만 재시도합니다.

## 개발용 카드 DB

현재 MapScene의 RouteMapController와 BattleScene의 PlayerDeck은 `Assets/Data/Development/RewardCardDatabase.asset`을 사용합니다. 이 DB는 기존 카드 9종과 희귀도별 베기/찌르기 더미 8종으로 구성됩니다. 더미는 기존 공격 효과를 사용하며 이름에 `테스트`가 붙습니다. 시작 덱에는 더미가 포함되지 않습니다.

원본 `Assets/Data/CardDatabase.asset`과 Google 시트는 변경하지 않았습니다. 개발용 DB는 원본의 스냅샷이므로 시트 갱신이 자동 반영되지 않습니다. 실제 데이터로 전환할 때는 시트의 획득 가능 여부/희귀도를 준비하고 재임포트한 뒤, **맵과 전투 양쪽**의 카드 DB 참조를 원본으로 교체해야 합니다. 개발용 ID를 포함한 진행 중 런은 재시작해야 합니다.

## 검증

`Tools > Duel Hero > Rewards > Validate card rewards`는 재현성, 전역 난수 보존, 후보 중복, 제외 카드, 후보 부족, 희귀도 분포와 소유 카드 감점을 검사합니다. 검증 데이터는 메모리에서 생성하고 제거하므로 실제 DB를 수정하지 않습니다.

씬 연결 도구는 `Tools > Duel Hero > Rewards > Set up development rewards`입니다. 열린 씬을 먼저 저장해야 하며, 기존 개발용 DB/설정이 있으면 재생성하지 않습니다. 일반 플레이에는 다시 실행할 필요가 없습니다.

수동 확인: MapScene 실행 → 일반 전투 승리 → 카드 클릭 또는 스킵 → 맵 복귀 → 다음 전투에서 획득 카드 확인. 플레이 종료 후 런을 이어가는 영속 저장 기능은 이번 범위에 포함하지 않습니다.

### 이번 구현의 확인 결과

- 희귀도 검증 20,000시드: 일반 12,396 / 고급 4,984 / 희귀 2,004 / 전설 616.
- 같은 등급의 미소유 1종과 소유 1종 비교 20,000시드: 소유 카드 3,990회 선택(기대 비율 20%).
- Editor 플레이 모드에서 MapScene → BattleScene → 보상 획득 → MapScene → 다음 전투의 덱 유지와 예약·실행을 확인했습니다. 전투 종료 조건은 디버그 HP 설정 후 실제 슬롯 실행으로 유도했고, 승패 결과 필드를 직접 바꾸지 않았습니다.
- 이동 실패를 런타임의 잘못된 맵 경로로 유도해, 획득이 한 번만 반영되고 재시도는 이동만 수행하는지 확인했습니다. 씬 파일의 경로 설정은 바꾸지 않았습니다.
- 스킵·후보 0종·보유 카드 사본 추가·연속 클릭·보스 승리·동시 사망 패배·단독 전투 승리/재시작을 확인했습니다.
- 최종 컴파일/콘솔 오류는 없으며 플레이 모드를 종료하고 원래 MapScene 편집 상태로 복귀했습니다.
