## 적용 범위

색상, 형태, 조명, 캐릭터와 UI의 관계를 검토하기 위한 전체 화면 이미지입니다. Unity 씬이나 UI 프리팹에 적용하지 않았습니다. 이미지 속 숫자와 범위 도식은 표현 예시이며 실제 카드 데이터는 Duel Hero 시트의 최신 내용을 사용해야 합니다. 버튼·카드·아이콘 등 개별 제작 리소스는 별도 분리 제작이 필요합니다.

### 전투

Use case: ui-mockup / stylized-concept. Project: DuelHero, a PC 2.5D tactical deckbuilding roguelike. Produce one polished landscape 16:9 GAME SCREEN LOOKDEV, full bleed, no contact sheet. Cohesive casual cartoon dark fantasy: chunky outlined hand-drawn 2D sprite characters in a simplified cel shaded 3D environment, playful spooky atmosphere, big readable shapes, charcoal blue-gray stone, desaturated teal shadows, restrained violet corruption, warm amber torchlight, cream UI text, thick dark outlines, slightly irregular beveled stone/parchment UI panels. Inspired by broad cartoon dark fantasy mood of Twisted Fate by Game Dynasty, original characters and original UI. Avoid photorealism, pixel art, excessive gore, ornate clutter, tiny illegible text, mobile portrait layouts. UI is an illustrated concept mockup, not production assets. Use only brief exact English UI labels. Scene: BATTLE. Fixed elevated three-quarter camera showing an EXACT 4 columns by 3 rows stone arena, all twelve cells clearly countable, no other grid tiles. One small hooded swordsman player in ochre cloak and one quirky horned violet goblin enemy, both flat illustrated sprites standing in a real dimensional courtyard. Sparse ruined arches beyond the grid. Subtle teal reachable-cell highlights and amber attack-range outlines never obscure actors. Top left PLAYER HP 30/40, ENERGY 3; top right ENEMY HP 18/24; top center ROUND 2 and enemy intent queue displaying ? / ATTACK / ?. Bottom UI: left compact MOVE and GUARD buttons; center exactly three reserved-action slots labeled 1 MOVE, 2 SLASH, 3 WAIT; right prominent EXECUTE button. Above bottom action queue, a compact available deck row of four ability cards SLASH, THRUST, HEAVY STRIKE, DASH with cost and cooldown badge, deliberate direct deck selection rather than random hand/draw/discard interface. Cards readable, arena largest area, well spaced, high quality indie game screenshot. No cursor. Title small DUEL HERO.
